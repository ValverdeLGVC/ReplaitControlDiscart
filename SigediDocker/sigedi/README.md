# SIGEDI

Sistema de gerenciamento de equipamentos.

## Requisitos

- Docker Desktop
- Docker Compose

## Instalação

Abra o terminal na pasta do projeto e execute:

docker compose up -d

## Acesso

Sistema:

http://localhost:3000

## Verificar containers

docker compose ps

## Ver logs

docker compose logs app

docker compose logs mysql

## Parar o sistema

docker compose down

## Reiniciar

docker compose restart
